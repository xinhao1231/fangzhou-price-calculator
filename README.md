# 方舟产品价格计算器

这是一个用于产品价格、包装、FOB 分摊和外箱信息计算的静态网页。

部署到 GitHub Pages 后，直接访问仓库的 Pages 地址即可使用。

点击顶部“方舟产品助手”进入独立聊天页，也可直接打开网站地址加 `#assistant`。返回计算器不会清除本次登录和对话。授权账号的临时令牌保存在当前标签页的 sessionStorage，刷新时向后台验证并恢复登录，有效8小时；不保存密码或 DeepSeek 密钥。关闭标签页或浏览器清理数据后可能需要重登，对话仍仅保存在页面内存。共享账号需配置 `chat-config.js` 中的后台地址，并在后台授权网站来源。

Netlify 部署时必须同时上传根目录的 `_redirects`，使 `/api/*` 转发到已有 Cloudflare 后台；当前 Netlify 域名使用同源连接，GitHub Pages 仍直接访问后台。此转发减少浏览器直连 workers.dev 的依赖，不保证任何地区网络都可用。Netlify 代理等待上限26秒，较慢的 AI 请求可能超时，不自动重发或清除登录状态。部署后应从实际使用网络测试“检测连接”、登录和聊天。

嵌套规则：放入另一产品内部的数量不另占CBM、不另计FOB运费，产品价与已选包装价仍保留；外层产品正常计费。部分嵌套需拆成嵌套与非嵌套两行。聊天、混装报价、PI及装箱单中的嵌套运费采用同一规则；实际能否装入以及外层包装是否变化需确认。
